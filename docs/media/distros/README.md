# Distribution icons

These small SVGs identify the distributions discussed in the project README.
They are documentation assets and are not installed as system themes or icons.

The paths come from [Simple Icons](https://github.com/simple-icons/simple-icons)
at revision `90646e4bf7f3b89df6c37e65baf3e7bc759a517c`. Each SVG uses the brand color
recorded in the same upstream metadata; the paths are unchanged.
[`SOURCE.json`](SOURCE.json) preserves the original URLs, color values and
brand-specific references.

| [CachyOS](cachyos.svg) | [CachyOS](https://cachyos.org/) |
