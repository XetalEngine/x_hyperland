## Fusion Files

The `fusion-files/` captures were produced on **November 19, 2026** by the native
Qt application in an isolated profile, using the repository's
`computer-view-tests` and `navigation-tests` capture paths. The test inventory
supplies example disks, partitions, an optical disc, USB storage and a Wine
prefix. These are actual widgets and layouts; no real disks were mounted for
the pictures. Capacities and usage figures are demonstration data.

| Files | What they show |
| --- | --- |
| `fusion-files/me.png`, `7.png`, `10.png`, `11.png` | Four classic Windows-style This PC main panes; the surrounding application uses StarCraft II. |
| `fusion-files/med.png`, `7d.png`, `10d.png`, `11d.png` | The four layouts using the StarCraft II palette and background gradient, with the selected system disk's preview. |
| `fusion-files/cards.png` | The existing Fusion Cards layout with uniform volume cards and compact system-partition icons. |
| `fusion-files/7d-jade-light.png` | 7D with Files pinned to Killer Instinct · Jade Temple in light mode. |
| `fusion-files/browsing-settings.png` | The larger configuration dialog's Browsing page, with all options visible. |
| `fusion-files/this-pc-settings.png` | The dedicated This PC page, with the default visibility choices enabled. |

The transfer speeds, counts and errors are demonstration data, not benchmark
results. The cube picture shows one monitor's scene. Asset hashes are recorded
in the repository's `assets-manifest.json`.
