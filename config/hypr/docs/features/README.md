# Feature screenshots

These images accompany the repository README and the installed `FEATURES.md`
guide. They are unchanged copies of screenshots, with no generated UI, cropping
or recoloring.

| File | Source and context |
| --- | --- |
| `kde-taskbar.png` | Author-supplied live desktop screenshot showing the KDE workspace indicator. |
| `kde-recorder.png` | Author-supplied live Recorder page with the KDE-mode title bar above the app. |
| `super-overlay-settings.png` | Author-supplied earlier Mystery 98 screenshot of the overlay-controls editor; it shows configuration, not the target window's overlays. |
| `monitor-cube.png` | Existing repository capture, `docs/screenshots/midnight-transit-cube.png`: the actual compositor's cube preview in an isolated session. |
| `transfer-card.png` | Existing repository capture, `docs/screenshots/midnight-transit-transfer-card.png`: production progress UI displaying a sample job. |
| `transfer-attention.png` | Existing repository capture, `docs/screenshots/midnight-transit-transfer-detail.png`: production attention queue displaying sample results. |

The transfer speeds, counts and errors are demonstration data, not benchmark
results. The cube picture shows one monitor's scene. Asset hashes are recorded
in the repository's `assets-manifest.json`.
