# XMusic default application

Verified official XMusic 0.1.2 installer for fresh HyperFusion installs, including offline media. The adjacent manifest records its published size and SHA-256. Setup runs it as the desktop user, registers the audio types reported by XMusic, and pins its launcher. Existing desktops keep their music-app choice.

Source: https://www.xetal.net/community/site/api/app-release.php?app=xmusic
